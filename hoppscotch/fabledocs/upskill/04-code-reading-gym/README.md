# 04 — Code Reading Gym

Reading code precisely is the highest-leverage mid-level skill — reviews, debugging, and interviews are all reading exercises with different framing.

1. [01-annotation-drills.md](01-annotation-drills.md) — 10 excerpts; annotate inputs/outputs/invariants/side-effects/failures
2. [02-trace-tables.md](02-trace-tables.md) — 5 step-by-step value traces
3. [03-fake-code-contrasts.md](03-fake-code-contrasts.md) — 10 bad-vs-better pairs mapped to real repo patterns
4. [04-review-katas.md](04-review-katas.md) — 8 fake PRs to review with graded findings

Cadence: one drill/kata per day beats a weekend binge. Keep a log of your rubric grades — the trend is the progress measure, and "I ran a structured reading practice on a 12-package production codebase" is itself an interview story.
