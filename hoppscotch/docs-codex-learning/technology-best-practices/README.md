# Technology Best Practices

This suite teaches the technologies Hoppscotch actually uses, through real files in this repository. It is not a generic Vue/Nest/Prisma tutorial.

Use it one technology at a time:

1. Read the technology map.
2. Open the cited files.
3. Copy the pattern into notes in your own words.
4. Do the mini practice tasks.
5. Ask Codex to quiz you or review your explanation.

This differs from the architecture suite by focusing on stack habits: how TypeScript, Vue, GraphQL, NestJS, Prisma, validation, state, and tests are used in code.
