# Mission Learning Path

This suite turns the Hoppscotch repo into an active training path. Each mission asks you to open real files, annotate meaningful blocks, answer questions, and self-grade.

Do not race. One good mission is better than five skimmed missions. The goal is to build the muscle of tracing unfamiliar code without panic.

## How The Mission System Works

Each mission includes:

- a concrete engineering concept,
- the design intent before reading,
- exact files and line ranges,
- annotated code,
- an aha moment,
- a Socratic checkpoint,
- self-grading criteria,
- and connections to the next mission.

## Recommended Pacing

- Tier 1: 1 mission per day.
- Tier 2: 2-3 missions per week.
- Tier 3: 1 mission per week, with notes.

## Using Codex Without Losing The Learning

Ask Codex to quiz you, check your trace, or review your diff. Avoid asking for final answers first. Good prompt:

```text
I am working on Mission N. I think the flow is A -> B -> C. Ask me questions that expose gaps. Give hints in stages.
```

This suite differs from normal docs because it is a workout. If you are not writing answers, you are only spectating.
