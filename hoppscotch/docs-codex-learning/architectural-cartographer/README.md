# Architectural Cartographer

This suite is a senior-engineer onboarding map for Hoppscotch. It starts with the whole-system mental model, then drills into folders, startup, routing, state, GraphQL, backend services, Prisma persistence, testing, debugging, and ownership.

Use it when you want to answer: "Where does this feature live, what calls what, what should I read next, and what risks should I notice?"

## Reading Order

1. `JOURNAL.md` for the inspection notes and teaching rationale.
2. `00-reading-map.md` for the first ten files to read.
3. `01-junior-engineer.md` for setup, folder orientation, and annotated entry points.
4. `02-mid-level-engineer.md` for end-to-end feature tracing and diff-reading practice.
5. `03-senior-engineer.md` for critique, testing, performance, and security review.
6. `04-reference-suite.md` for condensed playbooks.

## Working Through Checkpoints

For every checkpoint, answer before reading the self-grade section. A strong answer does not need perfect wording; it needs a correct dependency chain, named files, and an honest statement of uncertainty.

This suite differs from the mission suite because it is a map. The mission suite is a workout plan. The user-story suite is a ticket ladder.
